# Research

Investigations and candidate approaches. **Research is not specification.** A
document here describes what was explored, not what the product does — check
[[Current State]] before treating anything here as implemented.

Every research note should state its standing:

```text
External reference | Hypothesis | Candidate approach | Accepted approach | Implemented approach
```

Use [[Research Note]] as the template.
