<objective>
Raise the published dataset schema version, rewrite the two limitation statements that describe
the retired physics while keeping their ids, record the change in a changelog that belongs to
this dataset family, and produce committed evidence that all seven published datasets actually
moved.

Purpose: the seven datasets are computed live per HTTP request from committed inputs, so the
code fix already reaches them — there is nothing to batch-regenerate. What is genuinely missing
is the honesty layer around that fact: a version a consumer can compare against, a changelog
they can read, limitation text that is not describing arithmetic that no longer exists, and a
recorded before-and-after so the claim "the datasets were regenerated under corrected physics"
is checkable rather than asserted.

`L-CLIMATE` text, `public/reference-buildings/CHANGELOG.md`, an evidence test over all seven,
an ADR for the named-end-use split, and updated feature documentation.
