# Plan 03: Measurement & Annotation Tools

<objective>
Add measurement and annotation capabilities: dimension lines between two points, area labels on floor slabs, level markers at floor elevations, and section cut planes. Annotations use CSS2DRenderer for crisp text labels.
</objective>

<tasks>

<task id="1">
<title>Annotation geometry generators</title>
<read_first>
- src/lib/procedural/types.ts
- src/lib/layers/types.ts
</read_first>
<action>
Create `src/lib/annotations/dimension-line.ts`:
- Export `createDimensionLine(start: THREE.Vector3, end: THREE.Vector3): THREE.Group`
- Line between start and end using LineSegments + LineBasicMaterial({ color: 0x333333 })
- Arrow heads at both ends: small ConeGeometry rotated to point along line direction
- Distance label at midpoint: use THREE.Sprite with CanvasTexture rendering text
  - Format: "X.XX m" with white background, black text, small font
- Perpendicular tick marks at start and end
- Group name: "annotation-dimension"

Create `src/lib/annotations/area-label.ts`:
- Export `createAreaLabel(area: number, position: THREE.Vector3): THREE.Group`
- Sprite with CanvasTexture: "XX.X m²" text
- Semi-transparent white background pill shape
- Positioned slightly above the surface (y + 0.1)
- Group name: "annotation-area"

Create `src/lib/annotations/level-marker.ts`:
- Export `createLevelMarker(elevation: number, label: string, width: number): THREE.Group`
- Horizontal dashed line at elevation height, full building width
- LineDashedMaterial({ color: 0x666666, dashSize: 0.2, gapSize: 0.1 })
- Label at left end: "FL+X.Xm" or floor name (Sprite with CanvasTexture)
- Small triangle marker at left edge pointing right
- Group name: "annotation-level"

Create `src/lib/annotations/section-cut.ts`:
- Export `createSectionPlane(axis: "x" | "z", position: number, size: number): { plane: THREE.Plane, helper: THREE.PlaneHelper }`
- THREE.Plane for clipping
- PlaneHelper for visualization (semi-transparent colored plane)
- Helper material: MeshBasicMaterial({ color: 0x2196f3, transparent: true, opacity: 0.1, side: THREE.DoubleSide })
</action>
<acceptance_criteria>
- All 4 files exist in src/lib/annotations/
- Dimension line has line + arrows + distance label
- Area label has "XX.X m²" text sprite
- Level marker has dashed line + elevation label
- Section cut returns THREE.Plane + visual helper
- `pnpm build` passes
</acceptance_criteria>
</task>
