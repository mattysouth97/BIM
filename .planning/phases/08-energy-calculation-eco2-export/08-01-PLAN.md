# Plan 01: Energy Calculation Engine

<objective>
Create pure calculation functions for heat loss, annual energy demand, energy efficiency grade, and CO2 emissions. Plus a React hook that reactively computes all metrics from material-store and recipe-store.
</objective>

<tasks>

<task id="1">
<title>Climate data and heat loss calculator</title>
<read_first>
- src/lib/korean-building-codes.ts
- src/store/material-store.ts
- src/lib/material-types.ts
</read_first>
<action>
Create `src/lib/energy/climate-data.ts`:
- Export `SEOUL_CLIMATE = { hdd: 2700, cdd: 600, winterDesignTemp: -11.3, summerDesignTemp: 33.6, indoorTemp: 20, indoorCoolTemp: 26 }`
- Export type `ClimateData` with those fields
- Export `getClimateData(city?: string): ClimateData` — returns Seoul default (expandable later)

Create `src/lib/energy/heat-loss.ts`:
- Export interface `ElementHeatLoss`: { element: string, area: number, uValue: number, heatLoss: number, heatLossPerSqm: number }
- Export interface `HeatLossResult`: { elements: ElementHeatLoss[], totalHeatLoss: number, totalHeatLossPerSqm: number }
- Export `calculateHeatLoss(materials: MaterialProperties, recipe: BuildingRecipe, climate: ClimateData): HeatLossResult`
  - Wall: sum of wall areas × wall U-value × ΔT (indoor - winter design temp)
  - Roof: roof area × roof U-value × ΔT
  - Floor: floor area × floor U-value × ΔT (use indoor - 5°C for ground)
  - Window: total window area (wall area × WWR) × window U-value × ΔT
  - ΔT = indoorTemp - winterDesignTemp = 20 - (-11.3) = 31.3°C
  - Wall area = perimeter × totalHeight - window area
  - Perimeter = 2 × (footprintWidth + footprintDepth)
  - Return per-element breakdown + totals
</action>
<acceptance_criteria>
- `src/lib/energy/climate-data.ts` exports `SEOUL_CLIMATE` and `getClimateData`
- `src/lib/energy/heat-loss.ts` exports `calculateHeatLoss` returning `HeatLossResult`
- Heat loss formula: Q = U × A × ΔT per element
- Seoul ΔT = 31.3°C for winter
- `pnpm build` passes
</acceptance_criteria>
</task>

<task id="2">
<title>Annual demand, energy grade, and CO2</title>
<read_first>
- src/lib/energy/heat-loss.ts
- src/lib/energy/climate-data.ts
</read_first>
<action>
Create `src/lib/energy/annual-demand.ts`:
- Export interface `AnnualDemand`: { heatingDemand: number, coolingDemand: number, totalDemand: number, demandPerSqm: number }
- Export `calculateAnnualDemand(heatLoss: HeatLossResult, materials: MaterialProperties, recipe: BuildingRecipe, climate: ClimateData): AnnualDemand`
  - Heating demand = totalHeatLoss × HDD × 24 / 1000 / totalFloorArea (kWh/m²·yr)
  - Cooling demand = cooling heat gain × CDD × 24 / 1000 / totalFloorArea
  - Cooling heat gain: simplified as 60% of heat loss (solar + internal gains)
  - Adjust for HVAC efficiency: heatingDemand / (heatingEfficiency/100), coolingDemand / COP
  - totalFloorArea = footprintWidth × footprintDepth × floorCount

Create `src/lib/energy/energy-grade.ts`:
- Export type `EnergyGrade`: "1+++" | "1++" | "1+" | "1" | "2" | "3" | "4" | "5" | "6" | "7"
- Export `GRADE_THRESHOLDS`: Record mapping grade to max kWh/m²·yr
  - 1+++: 60, 1++: 90, 1+: 120, 1: 150, 2: 190, 3: 230, 4: 270, 5: 320, 6: 370
- Export `getEnergyGrade(demandPerSqm: number): EnergyGrade`
- Export `getGradeColor(grade: EnergyGrade): string` — green→red gradient

Create `src/lib/energy/co2-emissions.ts`:
- Export `KOREAN_GRID_EMISSION_FACTOR = 0.4594` (tCO2/MWh, 2023)
- Export interface `CO2Result`: { totalCO2: number, co2PerSqm: number }
- Export `calculateCO2(annualDemand: AnnualDemand, totalFloorArea: number): CO2Result`
  - CO2 = totalDemand × emissionFactor / 1000 (convert kWh to MWh)
</action>
<acceptance_criteria>
- All 3 files exist in src/lib/energy/
- Annual demand uses degree-day method with HDD/CDD
- Energy grade maps demand to Korean 1+++ through 7 scale
- CO2 uses 0.4594 tCO2/MWh factor
- `pnpm build` passes
</acceptance_criteria>
</task>
