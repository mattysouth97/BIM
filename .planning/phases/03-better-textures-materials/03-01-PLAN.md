    For each downloaded ZIP:
    1. Extract to a temp directory
    2. Copy the _Color.jpg -> public/textures/{name}/color.jpg
    3. Copy the _NormalGL.jpg -> public/textures/{name}/normal.jpg
    4. Copy the _Roughness.jpg -> public/textures/{name}/roughness.jpg
    5. Delete the ZIP and temp files

    If AmbientCG download fails (rate limit, etc.), use curl to download from Poly Haven as fallback:
    `https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/{asset_name}/{asset_name}_diff_1k.jpg`

    Target: 1024x1024 resolution, JPG format, ~100-200KB per map. Total ~2-3MB for all textures.

    IMPORTANT: Desaturate color maps slightly (reduce saturation by ~30%) to maintain the BIM structural-clarity aesthetic.    
    ```typescript
    import { useTexture } from "@react-three/drei";
    import * as THREE from "three";
    import { useMemo } from "react";

      normalMap: THREE.Texture;

      metalness: number;
      normalScale: [number, number];
    }

    export function useTexturedMaterial(
      strctCd: string,
      era?: BuildingEra,
      component?: "wall" | "column" | "slab" | "roof",
      mainPurpsCd?: string
    ): TexturedMaterialProps {
    ```

    Implementation:
    1. Call getTextureSet(strctCd, era, component) to get paths
    2. Call getPBRMaterial(strctCd, mainPurpsCd, era) for base color/metalness
    3. Use drei's `useTexture` to load all 3 maps in a single call: `useTexture([colorMap, normalMap, roughnessMap])`
    4. In useMemo, configure each texture:
       - Set `wrapS` and `wrapT` to `THREE.RepeatWrapping`
       - Set `repeat` from TextureSet.repeat
       - Set colorMap `colorSpace` to `THREE.SRGBColorSpace`
       - Normal and roughness maps stay in `THREE.LinearSRGBColorSpace`
    5. Return object with `map`, `normalMap`, `roughnessMap`, `color` (from getPBRMaterial — tints the texture), `metalness`, and `normalScale` (use [0.3, 0.3] for subtle depth — structural clarity, not photorealism)

    For BIM structural clarity:
    - normalScale should be subtle: [0.3, 0.3] for walls, [0.2, 0.2] for slabs/columns, [0.4, 0.4] for roof
    - The color from getPBRMaterial tints the texture (multiplied by Three.js) — this preserves the desaturated BIM look
    - Do NOT set roughnessMap intensity too high; let the base roughness from getPBRMaterial dominate

    Export a second simpler hook for components that just need the config without loading:
    ```typescript
    export function useTextureConfig(strctCd: string, era?: BuildingEra, component?: "wall" | "column" | "slab" | "roof"): TextureSet;
    ```
