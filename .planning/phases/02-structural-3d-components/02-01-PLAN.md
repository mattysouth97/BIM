  </files>
  <action>
1. Create wall-generator.tsx:
   - Takes floor, wallThickness, windowRatio, era, isGroundFloor, structureCode, useCode
   - Calls generateWallSegments() from wall-geometry.ts
   - Renders solid segments as BoxGeometry with PBR material (exterior color)
   - Renders glass segments as BoxGeometry (thin, ~6mm) with transparent glass material
   - Renders door voids as empty space (no geometry)
   - Each wall face: 4 outer walls positioned at floor edges, offset inward by wallThickness/2

2. Create slab-mesh.tsx:
   - Renders a thin horizontal slab at the bottom of each floor
   - BoxGeometry: width × slabThickness × depth
   - Position: floor.y + slabThickness/2
   - Concrete gray material, slightly different from walls
   - Edges visible for structural clarity

3. Create column-generator.tsx:
   - Takes floor dimensions, columnSpacing, structureCode, slabThickness
   - Generates a rectangular grid of columns within the footprint
   - RC/masonry: square columns (0.4m × 0.4m for residential, 0.6m for commercial)
   - Steel: rectangular columns (0.3m × 0.3m)
   - Column height: floor.height - slabThickness
   - Position: starting from slabThickness above floor.y
   - Material: darker concrete for RC, steel gray for steel frame
