<action>
Create `src/components/viewer/building-layers.tsx`:
- Export `BuildingLayers` component with props: `{ recipe: BuildingRecipe }`
- Uses `useLayerStore` to subscribe to visibility changes
- Creates `LayerManager` instance in useRef (dispose on unmount)
- useEffect on visibility changes:
  - For each layer where visibility is true and not yet generated:
    - Call `layerManager.getOrGenerate(id, recipe)`
    - Call `useLayerStore.getState().setGenerated(id)`
  - For all layers: call `layerManager.setVisible(id, visibility[id])`
- useFrame((state) => { layerManager.updateAnimations(state.clock.elapsedTime) })
- Render: `<primitive object={layerManager.getParentGroup()} />`
- Cleanup: dispose LayerManager on unmount or recipe change
</action>
<acceptance_criteria>
- `src/components/viewer/building-layers.tsx` contains `export function BuildingLayers`
- Component creates LayerManager in useRef
- useFrame calls updateAnimations with clock.elapsedTime
- Visibility changes trigger getOrGenerate for newly visible layers
- Renders primitive with layerManager.getParentGroup()
- Cleanup disposes LayerManager
- `pnpm build` passes
</acceptance_criteria>
</task>
