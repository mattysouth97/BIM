# Bounded real pilot and resumable corpus baseline generation

1. Measure three first-page register queries through normal same-origin production
   transport; preserve observed HTTP status, latency, count and completeness.
   Record advertised traffic separately from unknown actual daily quota.
2. Reuse diagnosticSourceFromLedger → ingestDrawingSet → buildLedgerBaselineModel
   → compileCanonicalModelToEngineInput → runSimulation and the shared energy
   helpers. Correct canonical primary mapping so it also includes the same fuel
   routing and capped PV before producing final records.
3. Strictly allowlist register fields, preserving long IDs as strings. Exclude
   unsupported rows with reasons. Do not retain owner/contact/household/address or
   arbitrary upstream payload fields in source cache or published artifacts.
4. Build immutable pinned job metadata, per-row outcome journal and checkpoint.
   Test resume, changed-input rejection, duplicate IDs, missing geometry and exact
   deterministic output. Produce coverage and assumption prevalence at generation.
5. Generate all 75 observed rows as release 0.1.0-pilot only after tests pass and
   generator commit is integrated. Pin integrated commit, timestamps and licence
   decision. Store artifacts outside git. Give immutable complete release to Phase5.

## Acceptance

- Real request/completeness measurements exist; daily quota remains null unless
  measured independently. SWEEP-01 stays partial when its ceiling is unavailable.
- At most 75 source rows; no national/full-scale claim or saturation load test.
- Every generated record carries stable ID/permalink, engine/schema/commit/time,
  provenance, licence and evidence tier; every failed row is logged as exclusion.
- Tests and TypeScript/scoped ESLint pass. Phase5 independently enforces publish
  completeness, privacy allowlist and immutable release metadata.
