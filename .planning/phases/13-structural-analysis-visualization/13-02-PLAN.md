    **Class: StructuralAnalysisLayer implements LayerGenerator**

    `generate(recipe, density)` builds a THREE.Group with name "layer-15-structural" containing:

    **A. Stress-Colored Column Overlay (STRUCT-02)**
    - Call `getColumnPositions(recipe)` to get XZ positions
    - Filter `recipe.floors` to above-ground floors only: `recipe.floors.filter(f => f.type === "above")`
    - For each floor, create columns at each position using the SAME positioning logic as structure-generator.ts:
      - colHeight = floor.height - recipe.slab.thickness
      - y = floor.y + recipe.slab.thickness + colHeight / 2
      - Column size = recipe.column.size (meters)
    - Use InstancedMesh with BoxGeometry(1, 1, 1) scaled per instance
    - Total instance count = aboveFloors.length * columnPositions.length
    - Guard: `Math.max(1, totalCount)` for InstancedMesh count
    - Calculate loads: `calcColumnLoad(recipe, columnPositions.length)` returns per-floor cumulative loads
    - Calculate capacity: `calcColumnCapacity(recipe)` returns single kN value
    - For each instance, compute stress ratio = floorLoad / capacity
    - Apply per-instance color via `im.setColorAt(idx, color)` using `getStressColor(ratio)` to get the hex number, then `color.set(hexNumber)`
    - CRITICAL: After all setColorAt calls, set `im.instanceColor!.needsUpdate = true`
    - Material: `new THREE.MeshStandardMaterial({ transparent: true, opacity: 0.7 })` — semi-transparent so underlying building columns show through
    - Set `im.userData.type = "structural-column"` for raycaster filtering
    - For each instance, store sizing label: `userData.sizingLabels[idx] = getRecommendedColumnSize(load) + " | " + Math.round(load) + " kN | " + Math.round(ratio * 100) + "% cap."`

    **B. Animated Load Path Arrows (STRUCT-01)**
    - For each column position and each above-ground floor, create a downward arrow (shaft + head)
    - Arrow geometry per arrow (individual Meshes grouped per floor, NOT InstancedMesh — per research recommendation for <600 arrows):
      - Shaft: CylinderGeometry(0.05, 0.05, arrowHeight * 0.7, 6)
      - Head: ConeGeometry(0.12, arrowHeight * 0.3, 8)
      - arrowHeight: scale based on floor load magnitude. Map from min-max load range to 0.3-1.5 range. Formula: `0.3 + 1.2 * (floorLoad - minLoad) / (maxLoad - minLoad || 1)`
    - Position each arrow below the column center for that floor: y = floor.y + recipe.slab.thickness + 0.1 (just above slab), pointing downward
    - Arrow orientation: rotate 180 degrees around X axis so cone points downward (arrow flows roof -> foundation)
    - Material: ShaderMaterial with uTime uniform for opacity pulse animation:
      ```
      vertexShader: standard passthrough (gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0))
      fragmentShader: uniform float uTime; uniform vec3 uColor;
        float pulse = 0.3 + 0.7 * (0.5 + 0.5 * sin(uTime * 3.14159));
        gl_FragColor = vec4(uColor, pulse);
      transparent: true, depthWrite: false, side: THREE.DoubleSide
      ```
    - uColor: white (1,1,1) for arrows — neutral against stress-colored columns
    - The LayerManager.updateAnimations() automatically pushes elapsed time to uTime for any ShaderMaterial — arrows get animation for free.
    - Group all arrows into a sub-group named "structural-arrows"

    **C. Foundation Markers**
    - At y=0 (ground level), for each column position, place a small flat disc:
      - CircleGeometry(recipe.column.size * 1.5, 16) rotated -PI/2 on X axis (horizontal)
      - MeshStandardMaterial color #6b7280 (gray), opacity 0.5, transparent
    - Group named "structural-foundations"

    **dispose():**
    - Traverse group, dispose all Mesh/InstancedMesh geometry and materials (same pattern as layer-14-microgrid.ts)
    - Set this.group = null
