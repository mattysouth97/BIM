<objective>
Parallelize the building ledger fetch and VWorld footprint fetch so both requests fire simultaneously when a building is selected.

Purpose: Currently `useBuildingFootprint` is called inside `BuildingScene`, which only mounts after `useBuildingDetail` resolves. This makes footprint fetch sequential (ledger first, then footprint). Hoisting both fetches to the same component mount removes this dependency chain and achieves CP-01.

Output: `useCompositeBuilding` hook + updated `building/[id]/page.tsx` that passes `footprintData` as a prop.
</objective>

    Create `src/hooks/use-composite-building.ts` as a "use client" hook.

    Accept params: `{ sigunguCd, bjdongCd, platGbCd?, bun?, ji? }` and optional `address?: string`.

    The 5 query objects:
    1. `{ queryKey: ["buildings", "title", params], queryFn: () => searchBuildings(params), enabled }`
    2. `{ queryKey: ["buildings", "recap", params], queryFn: () => getRecapInfo(params), enabled }`
    3. `{ queryKey: ["buildings", "floors", params], queryFn: () => getFloorInfo(params), enabled }`
    4. `{ queryKey: ["buildings", "areas", params], queryFn: () => getAreaInfo(params), enabled }`
    5. `{ queryKey: ["footprint", address], queryFn: () => fetchFootprint(address!), enabled: !!address && address.trim().length > 0, staleTime: 1000 * 60 * 30, retry: 1 }`

    Where `enabled` for queries 1-4 = `!!params.sigunguCd && !!params.bjdongCd`.

    For query 5, inline the `fetchFootprint` function (copy from `use-building-footprint.ts`):
    ```typescript
    async function fetchFootprint(address: string): Promise<FootprintResult> {
      if (!address || address.trim() === "") return { polygon: null, error: null };
      const res = await fetch(`/api/vworld/footprint?address=${encodeURIComponent(address)}`);
      if (!res.ok) return { polygon: null, error: `HTTP ${res.status}` };
      return res.json();
    }
    ```

    Export interface:
    ```typescript
    export interface CompositeBuildingResult {
      title: ApiListResponse<BrTitleInfo> | undefined;

      areas: ApiListResponse<BrAreaInfo> | undefined;
      footprintData: FootprintResult | undefined;
      isLoading: boolean;
      isFootprintLoading: boolean;
      isError: boolean;
      errors: (Error | null)[];
    }
    ```

    `isLoading = results.some(r => r.isLoading)`
    `isFootprintLoading = results[4].isLoading`
    `isError = results.slice(0, 4).some(r => r.isError)` (footprint errors are soft — do not set isError)
