2. Add a new method to the `LayerManager` class (after the existing `setVisible` method):

```typescript
/** Set visibility for a MEP sub-group (electrical, HVAC, lighting, DHW). */
setMepSubVisible(subId: MepSubLayerId, visible: boolean): void {
  const mepGroup = this.groups.get("mep");
  if (!mepGroup) return;
  const child = mepGroup.getObjectByName(`sub-${subId}`);
  if (child) child.visible = visible;
}
```

This uses Three.js `getObjectByName()` which recursively searches children. The sub-group names
are `sub-mep-electrical`, `sub-mep-hvac`, `sub-mep-lighting`, `sub-mep-dhw` — set by
mep-coordinator's `setupMepSubGroups()`.

Do NOT modify `setVisible()`, `disposeLayer()`, or any other existing method. `disposeLayer("mep")`
already traverses all children recursively — sub-groups are disposed automatically.

**In building-layers.tsx:**

1. Add `import { MEP_SUB_IDS } from "@/lib/layers/types";` to existing imports.

2. Add a second `useLayerStore` selector for `mepSubVisibility`:
   ```typescript

   ```

3. Add a SECOND useEffect (after the existing visibility sync useEffect) that syncs sub-layer state:
   ```typescript
   // Sync MEP sub-layer visibility to Three.js sub-groups
   useEffect(() => {
     const manager = managerRef.current;
     if (!manager) return;
     for (const subId of MEP_SUB_IDS) {
       manager.setMepSubVisible(subId, mepSubVisibility[subId]);
     }
   }, [mepSubVisibility, visibility]);
   ```

   CRITICAL: The dependency array MUST include BOTH `mepSubVisibility` AND `visibility`.
   Why: When the user turns the main MEP toggle off then back on, Three.js propagates
   `.visible = true` to all children, overriding sub-group states. By including `visibility`
   in deps, this useEffect re-runs after the main toggle change and re-applies the correct
   sub-group states. This implements the "main MEP toggle off->on restores previous sub-layer
   states" requirement from CONTEXT.md.

Do NOT modify the existing visibility useEffect, the useFrame call, or the cleanup useEffect.
All changes are additive.
