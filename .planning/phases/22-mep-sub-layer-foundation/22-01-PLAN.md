Modify layer-store.ts to:

1. Add `import { persist } from "zustand/middleware";` alongside the existing zustand import.

2. Add `import type { MepSubLayerId } from "@/lib/layers/types";` and `import { MEP_SUB_IDS } from "@/lib/layers/types";` (keep existing ALL_LAYER_IDS import).

3. Extend the `LayerState` interface with 3 new members:
   - `mepSubVisibility: Record<MepSubLayerId, boolean>;`
   - `toggleMepSub: (id: MepSubLayerId) => void;`
   - `setMepSubVisible: (id: MepSubLayerId, visible: boolean) => void;`

4. Add a default for mepSubVisibility (all true):
   ```typescript
   const defaultMepSubVisibility = Object.fromEntries(
     MEP_SUB_IDS.map((id) => [id, true])
   ) as Record<MepSubLayerId, boolean>;
   ```

5. Wrap the existing `create<LayerState>()((set) => ...)` call in `persist()` middleware, following the workspace-store.ts pattern:
   ```typescript
   export const useLayerStore = create<LayerState>()(
     persist(
       (set) => ({
         // ... all existing state and actions unchanged ...

         mepSubVisibility: { ...defaultMepSubVisibility },

         toggleMepSub: (id) =>
           set((state) => ({
             mepSubVisibility: {
               ...state.mepSubVisibility,
               [id]: !state.mepSubVisibility[id],
             },
           })),

         setMepSubVisible: (id, visible) =>
           set((state) => ({
             mepSubVisibility: { ...state.mepSubVisibility, [id]: visible },
           })),
       }),
       {
         name: "bim-layer-store",
         partialize: (s) => ({
           mepSubVisibility: s.mepSubVisibility,
         }),
       }
     )
   );
   ```

   IMPORTANT: The `partialize` must ONLY persist `mepSubVisibility`. Do NOT persist `visibility`, `generated`, or `density` — those are runtime state that should reset on reload (matches current behavior where they default to all-true/all-false/50).

6. Update the `resetAll` action to also reset mepSubVisibility:
   ```typescript
   resetAll: () =>
     set({
       visibility: { ...defaultVisibility },
       generated: { ...defaultGenerated },
       density: { ...defaultDensity },
       mepSubVisibility: { ...defaultMepSubVisibility },
     }),
   ```

All existing actions (toggleLayer, setLayerVisible, setGenerated, setDensity) must remain exactly as they are. Only additive changes.
