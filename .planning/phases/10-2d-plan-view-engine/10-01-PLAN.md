# Plan 01: Plan View Camera + Wall Drawing Tool

<objective>
Create a 2D orthographic plan view with camera toggle, grid overlay, and wall drawing tool. Users click two points to create wall segments that render in both 2D and 3D.
</objective>

<tasks>

<task id="1">
<title>Plan store and plan view camera</title>
<read_first>
- src/store/authoring-store.ts
- src/components/viewer/building-scene.tsx
- src/components/viewer/scene-controls.tsx
</read_first>
<action>
Create `src/store/plan-store.ts`:
- Interface `WallSegment`: { id: string, start: [number, number] (x,z), end: [number, number] (x,z), thickness: number (default 0.2m), height: number (default 3.0m), floor: number }
- Interface `PlanState`:
  - walls: WallSegment[]
  - viewMode: "3d" | "plan"
  - drawingWall: { start: [number, number] } | null (active drawing state)
  - activeFloor: number (which floor level to draw on, default 0)
  - gridSize: number (default 0.5m)
- Actions: addWall(wall), removeWall(id), setViewMode(mode), startDrawing(start), cancelDrawing(), setActiveFloor(n), setGridSize(n)
- Export as `usePlanStore`

Create `src/components/viewer/plan-view.tsx`:
- R3F component that switches to orthographic camera when viewMode === "plan"
- Use useThree() to swap camera: create OrthographicCamera looking down Y axis
- Camera positioned at (0, buildingHeight + 20, 0) looking at (0, activeFloor * floorHeight, 0)
- Zoom controls: scroll to zoom orthographic camera (adjust left/right/top/bottom)
- Disable OrbitControls rotation in plan view (allow pan only)
- Export `PlanView`
</action>
<acceptance_criteria>
- `src/store/plan-store.ts` contains `export const usePlanStore`
- Store has walls array, viewMode, drawingWall state
- `src/components/viewer/plan-view.tsx` switches to orthographic camera
- Plan view looks straight down Y axis
- `pnpm build` passes
</acceptance_criteria>
</task>

<task id="2">
<title>Grid overlay and wall drawing tool</title>
<read_first>
- src/store/plan-store.ts
- src/components/viewer/plan-view.tsx
- src/store/authoring-store.ts
</read_first>
<action>
Create `src/components/viewer/plan-grid.tsx`:
- R3F component rendering a grid in plan view
- Use THREE.GridHelper(size, divisions) at y=0.01 (slightly above ground)
- Grid size: 50m × 50m, divisions based on gridSize from plan-store
- Subtle gray lines (#e0e0e0) with stronger lines every 5m (#999999)
- Only visible in plan view mode
- Export `PlanGrid`

Create `src/components/viewer/wall-drawer.tsx`:
- R3F component for interactive wall drawing
- Active only when viewMode === "plan" AND isAuthoring === true
- Click handler: raycast to ground plane (y=0)
  - First click: startDrawing(clickPoint) — show preview line from start to cursor
  - Second click: create WallSegment with start/end, addWall to store, cancel drawing
- Preview: LineSegments from start point to current mouse position (dashed, blue)
- Render existing walls as thick LineSegments in plan view (2D representation)
  - Wall color: dark gray #333, linewidth via custom shader or thick BoxGeometry
- In 3D view: render walls as BoxGeometry (width=thickness, height=wallHeight, depth=distance)
  - MeshStandardMaterial({ color: 0xd4d4d4, roughness: 0.7 })
- Right-click or Escape: cancel current drawing
- Export `WallDrawer`
</action>
<acceptance_criteria>
- `src/components/viewer/plan-grid.tsx` renders grid overlay
- `src/components/viewer/wall-drawer.tsx` handles click-to-draw walls
- First click starts, second click finishes wall segment
- Walls render as lines in plan view, extruded boxes in 3D
- Escape cancels drawing
- `pnpm build` passes
</acceptance_criteria>
</task>
