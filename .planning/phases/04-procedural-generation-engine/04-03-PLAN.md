**A) Create `src/components/viewer/procedural-building-model.tsx`:**

```
"use client";
```

This component wraps ProceduralBuilding for R3F. Key design decisions:

1. **useMemo for generation:** Instantiate ProceduralBuilding and call generate() in useMemo, keyed on the BuildingGeometry object. Use toRecipe() to convert.

2. **Texture application:** The procedural generator creates materials from PBRMaterialConfig (color + roughness + metalness). For texture maps, load them via useTexturedMaterial hook and apply to the InstancedMesh materials AFTER generation. In a useEffect, traverse the group, find each named InstancedMesh, and update its material's map/normalMap/roughnessMap properties from useTexturedMaterial results.

   Load 4 texture sets:
   - wall textures: `useTexturedMaterial(strctCd, era, "wall", mainPurpsCd)`
   - slab textures: `useTexturedMaterial(strctCd, era, "slab")`
   - column textures: `useTexturedMaterial(strctCd, era, "column")`
   - roof textures: `useTexturedMaterial(strctCd, era, "roof", undefined, roofType)`

   In useEffect after group is generated:
   - Find the "facade" sub-group. Within it, find InstancedMesh with userData.type === "solidPanel" — apply wall textures to its material.
   - Find "slabs" InstancedMesh — apply slab textures.
   - Find "columns" InstancedMesh — apply column textures.
   - Find "roof" Mesh — apply roof textures.
   - Glass and mullion materials do NOT get textures (glass is transparent, mullions are metallic).

   To apply textures to a material:
   ```typescript
   const mat = mesh.material as THREE.MeshStandardMaterial;
   mat.map = texProps.map;
   mat.normalMap = texProps.normalMap;
   mat.normalScale.copy(texProps.normalScale);
   mat.roughnessMap = texProps.roughnessMap;
   mat.needsUpdate = true;
   ```

3. **Floor selection via raycaster on slab InstancedMesh:**

   The R3F `onClick` event on the primitive already provides `event.instanceId` for InstancedMesh. Use it:

   ```typescript
   const handleSlabClick = useCallback((event: ThreeEvent<MouseEvent>) => {
     event.stopPropagation();
     if (event.instanceId === undefined) return;
     const floor = builderRef.current?.getFloorFromInstanceId(event.instanceId);
     if (!floor) return;

     // Toggle selection
     const newFloorNo = selectedFloor === floor.floorNo ? null : floor.floorNo;
     setSelectedFloor(newFloorNo);

     // Report to parent as FloorGeometry (map FloorSpec back)
     if (onFloorSelect) {
       if (newFloorNo !== null) {
         const floorGeo = geometry.floors.find(f => f.floorNo === floor.floorNo) ?? null;
         onFloorSelect(floorGeo);
       } else {
         onFloorSelect(null);
       }
     }
   }, [selectedFloor, onFloorSelect, geometry.floors]);
   ```

   For hover highlighting on slabs: use onPointerOver/onPointerOut with instanceId. Update the slab instance color by calling `slabMesh.setColorAt(instanceId, highlightColor)` and `slabMesh.instanceColor.needsUpdate = true`. On selection, set the selected instance to gold (#FFD700). On deselect, restore original color.

4. **Dispose on unmount:**
   ```typescript
   useEffect(() => {
     return () => { builderRef.current?.dispose(); };
   }, []);
   ```

5. **Render with R3F primitive:**
   ```typescript
   return (
     <group>
       {group && <primitive object={group} />}
     </group>
   );
   ```

   But the slab click handler needs to be on the slab mesh specifically. Extract the slab mesh and render it with event handlers:

   Actually, with `<primitive object={group} />`, R3F propagates events to children. So attach onClick to the primitive's slab child by wrapping it. Better approach: render the whole group via primitive, and attach a transparent onClick handler at the group level that checks `event.object.name === "slabs"` or checks `event.object.userData.type`.

   Simplest: use `<primitive object={group} onClick={handleClick} onPointerOver={handleHover} onPointerOut={handleUnhover} />` and filter by event.object inside the handler.
