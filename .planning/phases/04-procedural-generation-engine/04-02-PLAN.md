Output: `facade-generator.ts` (instanced glass/mullion/panel grid), `structure-generator.ts` (instanced slabs/columns + roof), `procedural-building.ts` (composer class).

Create `src/lib/procedural/facade-generator.ts`. This file is pure Three.js — no React imports.

Import THREE from "three" and types from "./types".

Export function `generateFacade(recipe: BuildingRecipe): THREE.Group` that:

**1. Helper: `pbrToMaterial(config: PBRMaterialConfig): THREE.MeshStandardMaterial`**
Create a MeshStandardMaterial from PBRMaterialConfig. Handle transparent/opacity/emissive fields. Set `side: THREE.FrontSide`. This is a local helper, not exported.

**2. Count instances first (pre-pass):**
For each above-ground floor, for each of the 4 wall faces (front/back/left/right):
- Calculate clear wall height = floor.height - recipe.slab.thickness
- Calculate wall face length (front/back = footprintWidth, left/right = footprintDepth)
- Calculate number of window columns: same logic as wall-geometry.ts layoutWindows — `maxCount = Math.floor((wallLength - 2 * cornerInset - mullionWidth) / windowSpacing)`, `count = Math.max(1, Math.round(maxCount * Math.min(windowRatio / 0.4, 1.0)))`
- Each window column produces: 1 glass instance OR 1 solid panel instance (based on solidPanelChance with seeded random using floorNo * 100 + colIndex as seed)
- Each window column ALWAYS produces mullion frame pieces: 2 vertical mullions (left + right of window) + 1 horizontal mullion (lintel above window) + 1 horizontal mullion (sill below window). But merge adjacent mullions — between two windows, only one vertical mullion is needed. So per column: contribute to shared mullion grid.
- Simpler approach for mullions: lay out a GRID of mullions. Horizontal mullions at each floor line (slab level) spanning the full wall width minus corner insets. Vertical mullions at each window column center +/- windowWidth/2. This creates the rectilinear mullion grid.

Simplify the mullion instancing: use two InstancedMesh — one for horizontal mullion bars, one for vertical mullion bars.
- Horizontal bars: one per floor line per wall face, sized (wallLength - 2*cornerInset) x mullionWidth x mullionDepth
- Vertical bars: one per window column edge per floor per wall face, sized mullionWidth x clearHeight x mullionDepth

Actually, for simplicity and performance, use FOUR InstancedMesh total for the facade:
- `glassInstances`: InstancedMesh with PlaneGeometry(1,1) — each instance scaled to windowWidth x windowHeight and positioned
- `solidPanelInstances`: InstancedMesh with BoxGeometry(1,1, wallThickness) — each instance scaled to window cell size
- `hMullionInstances`: InstancedMesh with BoxGeometry(1, mullionWidth, mullionDepth) — horizontal bars at slab lines
- `vMullionInstances`: InstancedMesh with BoxGeometry(mullionWidth, 1, mullionDepth) — vertical bars at window column edges

**3. First pass — count all instances across all floors and faces.** Track:
- `glassCount`, `solidCount`, `hMullionCount`, `vMullionCount`

**4. Create InstancedMesh objects:**
```typescript
const glassGeo = new THREE.PlaneGeometry(1, 1);
const glassMat = pbrToMaterial(recipe.materials.glass);
const glassIM = new THREE.InstancedMesh(glassGeo, glassMat, glassCount);
glassIM.castShadow = false; glassIM.receiveShadow = true;
```
Similarly for solid panels (BoxGeometry(1,1,1)), hMullions (BoxGeometry(1,1,1)), vMullions (BoxGeometry(1,1,1)).

Mullion material: `pbrToMaterial(recipe.materials.mullion)`.
Solid panel material: `pbrToMaterial(recipe.materials.wall)`.

**5. Second pass — set instance matrices:**
For each above-ground floor, for each of 4 faces:
- Face transform: position and rotation like wall-geometry.ts (front at +z, back at -z rotated PI, right at +x rotated PI/2, left at -x rotated -PI/2).
- Half-widths: `halfW = footprintWidth / 2`, `halfD = footprintDepth / 2`.
- Wall base Y = floor.y + slab.thickness.
- Clear height = floor.height - slab.thickness.

For glass/solid instances:
- For each window column index, compute local X position (centered distribution like wall-geometry.ts)
- Y position = sillHeight + windowHeight/2 (relative to wall base)
- Use seeded random: `((floorNo * 397 + colIndex * 71) % 100) / 100 < solidPanelChance` to decide solid vs glass
- Glass: position at wall face center, offset outward by wallThickness/2 + 0.001 (flush with wall exterior), then INSET by glassInset (so final Z in local face coords = wallThickness/2 - glassInset)
- Solid panel: position at wall center (same as wall box position), flush with wall exterior
- Create a composed matrix: `new THREE.Matrix4().compose(worldPosition, quaternion, scale)`
- Glass scale: (windowWidth, windowHeight, 1)
- Solid scale: (windowWidth, windowHeight, wallThickness)

For mullion instances:
- Horizontal mullions: at each floor's slab line (y = floor.y), spanning wallLength - 2*cornerInset
  - Also at top of each floor (y = floor.y + floor.height - slab.thickness) if it's the top floor
  - Position: centered on face, at the Y of each slab line, extruded outward by mullionDepth/2 from wall exterior face
  - Scale: (wallLength - 2*cornerInset, mullionWidth, mullionDepth)
- Vertical mullions: at each window column left and right edges
  - Position: at X = windowCenter +/- windowWidth/2, spanning clearHeight per floor
  - Scale: (mullionWidth, clearHeight, mullionDepth)
  - Do NOT place vertical mullions within cornerInset of wall edges

**6. Add parapet at building top:**
Add a horizontal mullion instance at the very top of the building (y = totalHeight), spanning each face, with height = parapetHeight. Use the mullion material. This can be added as extra instances in the hMullion InstancedMesh (account for in count).

**7. Set userData on each InstancedMesh** for identification:
```typescript
glassIM.userData = { type: "glass" };
solidIM.userData = { type: "solidPanel" };
```

**8. Assemble group:**
```typescript
const group = new THREE.Group();
group.add(glassIM, solidIM, hMullionIM, vMullionIM);
return group;
```

**9. Ground floor treatment:**
For the ground floor front face, replace the central 1-2 window cells (where a door would be) with a door-height solid panel using the groundFloor material color. This is a special case in the instance matrix loop — when isGroundFloor && face === "front" && colIndex is central, use door height (2.4m) instead of window height and use groundFloor material. Since InstancedMesh uses one material, create a SEPARATE small InstancedMesh for ground floor door panels (count will be small — 1-2 per building).

Actually, to keep draw calls under 10, skip the separate door mesh. Instead, mark central ground-floor front-face cells as solid panels (they'll use the wall material). The visual difference is sufficient — ground floors having solid panels at center reads as entrance. This avoids an extra draw call.

Total draw calls from facade: 4 (glass, solid panels, h-mullions, v-mullions).

```typescript
export class ProceduralBuilding {
  private group: THREE.Group | null = null;
  private recipe: BuildingRecipe;

  constructor(recipe: BuildingRecipe) {
    this.recipe = recipe;
  }

  generate(): THREE.Group {
    this.dispose(); // clean up previous

    const group = new THREE.Group();
    group.name = "ProceduralBuilding";

    // Facade (4 InstancedMesh)
    const facade = generateFacade(this.recipe);
    facade.name = "facade";
    group.add(facade);

    // Slabs (1 InstancedMesh)
    const slabs = generateSlabs(this.recipe);
    slabs.name = "slabs";
    group.add(slabs);

    // Columns (1 InstancedMesh)
    const columns = generateColumns(this.recipe);
    columns.name = "columns";
    group.add(columns);

    // Roof (1 Mesh)
    const roof = generateRoof(this.recipe);
    roof.name = "roof";
    group.add(roof);

    this.group = group;
    return group;
  }

  /** Get the slab InstancedMesh for raycaster floor selection */
  getSlabMesh(): THREE.InstancedMesh | null {
    if (!this.group) return null;
    return this.group.getObjectByName("slabs") as THREE.InstancedMesh | null;
  }

  /** Look up floor from slab instance ID */
  getFloorFromInstanceId(instanceId: number): FloorSpec | null {
    const slabs = this.getSlabMesh();
    if (!slabs) return null;
    const map = slabs.userData.instanceToFloor as Map<number, FloorSpec> | undefined;
    return map?.get(instanceId) ?? null;
  }

  /** Update recipe and regenerate */
  updateRecipe(recipe: BuildingRecipe): THREE.Group {
    this.recipe = recipe;
    return this.generate();
  }

  /** Dispose all geometry and materials */
  dispose(): void {
    if (!this.group) return;
    this.group.traverse((obj) => {
      if (obj instanceof THREE.Mesh || obj instanceof THREE.InstancedMesh) {
        obj.geometry.dispose();
        if (Array.isArray(obj.material)) {
          obj.material.forEach(m => m.dispose());
        } else {
          obj.material.dispose();
        }
      }
    });
    this.group = null;
  }

  getGroup(): THREE.Group | null {
    return this.group;
  }
}
```
