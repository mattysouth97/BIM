  <action>
    First install dependencies: `pnpm add three-bvh-csg three-mesh-bvh`

    Create `src/components/viewer/opening-drawer.tsx`:

    1. **State:** Read from plan-store: `walls`, `openings`, `drawingMode`, `addOpening`, `activeFloor`, `viewMode`. Add local state for `selectedPresetId` (default "door-900") and `snapPreview` (the nearest wall snap point or null).

    2. **Active condition:** `viewMode === "plan" && drawingMode === "opening"`.

    3. **Snap logic (mouse move):** When active, on mouse move:
       - Raycast to ground plane (same pattern as WallDrawer: THREE.Plane(0,1,0) + ray.intersectPlane).
       - For each wall on activeFloor, call `projectOntoWall(mouseX, mouseZ, wall.start[0], wall.start[1], wall.end[0], wall.end[1])`.
       - Find the wall with smallest `dist` where `dist < 1.0` (snap threshold).
       - Set `snapPreview` to `{ wallId, t, wx, wz, angle }` where angle is `Math.atan2(wall.end[1]-wall.start[1], wall.end[0]-wall.start[0])`.
       - If no wall within threshold, set `snapPreview` to null.

    4. **Placement (click):** When active and snapPreview is not null, on click:
       - Look up the selected preset from DOOR_PRESETS or WINDOW_PRESETS by selectedPresetId.
       - Compute wall length from the target wall. If preset width > wall length, reject with console.warn (do not place).
       - Call `addOpening({ id: crypto.randomUUID(), wallId: snapPreview.wallId, t: snapPreview.t, presetId: selectedPresetId, floor: activeFloor })`.

    5. **Snap preview visual:** When snapPreview is not null, render a thin colored box at the snap point showing the opening width along the wall direction. Use the `primitive` wrapper pattern. Color: `0x3b82f6` (blue) with 50% opacity.

    6. **Render placed openings (plan view only):**
       For each opening on activeFloor:
       - Look up the wall by `opening.wallId` from walls array. If wall not found, skip.
       - Compute world position: `wx = wall.start[0] + t * (wall.end[0] - wall.start[0])`, `wz = wall.start[1] + t * (wall.end[1] - wall.start[1])`.
       - Compute wall angle: `Math.atan2(wall.end[1]-wall.start[1], wall.end[0]-wall.start[0])`.
       - Look up preset from DOOR_PRESETS or WINDOW_PRESETS by `opening.presetId`.

       **Door symbol (arc sweep):** Use `THREE.EllipseCurve` to create an arc from 0 to Math.PI/2 with radius = preset.width. Sample at 16 points. Create a BufferGeometry line at `y = 0.03`. Add a straight line from hinge to door edge. Render using `primitive` pattern. Color: `0x8b4513` (brown).

       **Window symbol (parallel double lines):** Two thin boxes (length = preset.width, height = 0.015, depth = wall.thickness * 0.3) offset +/- from wall center in the perpendicular direction. Color: `0x42a5f5` (light blue). Position at `y = 0.03`.

       Both symbols positioned at the opening's world coordinates and rotated by wall angle.

    7. Export `OpeningDrawer` as the main component, and export `selectedPresetId` getter/setter for the overlay to use. Use a module-level ref or a tiny Zustand atom: `export const useOpeningPreset = create<{presetId: string; setPresetId: (id: string) => void}>()((set) => ({ presetId: "door-900", setPresetId: (id) => set({ presetId: id }) }))`.
