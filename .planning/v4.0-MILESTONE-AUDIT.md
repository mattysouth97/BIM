## What Was Built

### Phase 19: Coordinate System Foundation
- `src/lib/gis/gis-transform.ts` — proj4 site-specific TM projection with local origin subtraction
- VWorld API key moved to `VWORLD_API_KEY` env var, domain to `VWORLD_DOMAIN`
- Korean peninsula bounding box assertions with typed `GisCoordinateError`
- 7 unit tests, round-trip accuracy <1m at 2km verified

### Phase 20: Footprint Extrusion
- `src/lib/gis/earcut-extrude.ts` — earcut triangulation for concave polygons with holes
- `extractPolygon()` upgraded to return raw WGS84 rings (equirectangular approximation removed)
- `BuildingRecipe.footprintPolygon` type upgraded to GeoJSON-style `[number,number][][]`
- Structure generator: polygon slabs per floor via earcut
- Facade generator: polygon-edge face descriptors for N-sided buildings
- 11 unit tests for extrusion utility

### Phase 21: Composite Pipeline
- `src/hooks/use-composite-building.ts` — useQueries parallel fetch orchestrator
- Footprint fetch hoisted to page level, passed as prop to BuildingScene
- Loading overlay with spinner during fetch
- Graceful fallback to rectangular model on footprint failure
