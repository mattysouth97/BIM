## Deviations from plan

### Auto-fixed issues

**1. [Rule 3 - Blocking] Vercel CLI 58.9.4 OIDC/token pairing validation broke `blob put`**
- **Found during:** Task 5 step 2 (first put failed before any upload)
- **Issue:** `vercel blob put` hard-fails when exactly one of `VERCEL_OIDC_TOKEN` / `BLOB_STORE_ID` is set. A `vercel env pull`ed `.env.local` carries `VERCEL_OIDC_TOKEN` but no `BLOB_STORE_ID`, and the publish script spawns the CLI with the inherited environment.
- **Fix:** sanitize the child env in `publish-reference-glbs.mjs` (drop both variables) so the CLI takes its documented read-write-token path. Contract unchanged: pathname + public + overwrite + no random suffix.
- **Files modified:** `scripts/publish-reference-glbs.mjs`
- **Commit:** `f277eef`

**2. [Rule 3 - Blocking] Sandbox `PLAYWRIGHT_BROWSERS_PATH` pointed at an empty cache**
- **Found during:** Task 5 step 1 (all 3 baseline tests failed to launch a browser)
- **Fix:** cleared the variable for the test runs so Playwright uses the default `ms-playwright` installation, where `chromium_headless_shell-1208` is present. Environment-only; no repo change.
