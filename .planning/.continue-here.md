## Read this before adding model twelve

**It will probably break the build.** `public/` is 549 MB of binary geometry
shipped through the app bundle, and two different ceilings were hit today by
actual failure:

1. A serverless function traced to **296.3 MB** against Vercel's 250 MB limit.
   Fixed with `outputFileTracingExcludes`. `next.config.ts` already carried a
   comment claiming its *include* prevented this — an include only ADDS files,
   so nothing was keeping the meshes out; the limit had simply not been reached.
2. `pnpm run build` then **OOM'd twice** on the 4-core/8 GB builder. Cleared by
   enabling Enhanced Build Machines (8 cores/16 GB), which is now load-bearing.

Both are the same cause. Moving GLBs to blob/CDN storage is the real fix.

Tip that saves a full failed build cycle: the `Build machine configuration:`
line at the top of a deploy log tells you in seconds whether Enhanced Builds
is actually active.
