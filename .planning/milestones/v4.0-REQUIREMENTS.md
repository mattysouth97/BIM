## Out of Scope

| Feature | Reason |
|---------|--------|
| CesiumJS/Mapbox dual-engine rendering | Two WebGL contexts = GPU memory competition |
| Full terrain mesh from DEM | High complexity, defer to v5.0+ |
| Client-side tile caching/stitching | VWorld WMS single-image approach avoids this |
| Real-time 3D building streaming from VWorld | API permanently closed (July 2019) |
