## E2E Flow

**Building selection → composite render:** COMPLETE
1. User selects building → `useCompositeBuilding` + `useBuildingFootprint` fire in parallel
2. Footprint API returns WGS84 polygon rings
3. `createSceneProjection` (proj4 TM) projects rings to local [x,z] coords
4. `extrudePolygon` (earcut) triangulates polygon per floor
5. `facade-generator` wraps polygon faces with era-based PBR materials
6. Loading overlay hides during fetch, composite renders on completion
7. If footprint unavailable → rectangular fallback (automatic via undefined guard)
