<objective>
Extend `generateECO2Input()` so the exported JSON includes a new top-level `subSystems` block
containing HVAC system type, lighting power density, and DHW system type — each stamped with
`dataSource: "estimated-inferred"` — while leaving the existing envelope-only output shape
unchanged for callers that do not opt in.

Purpose: GX auditors receive per-system fields in the ECO2 input file so they can hand-feed
sub-system data into ECO2 software alongside the envelope data already supported. Sub-system
values are inferred from Korean building-code defaults (not measured), so explicit provenance
metadata is mandatory per STD-02.

Output: Updated `eco2-export.ts` with `ECO2SubSystems` interface + `buildSubSystems()` pure
helper + extended `ECO2ExtraOptions`. New Vitest file covering SC1/SC2/SC3. Updated call site
in `energy-cards.tsx` that opts in to the new block.
</objective>
