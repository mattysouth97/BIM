  <action>
    **Create `src/store/workspace-store.ts`:**

    Use `"use client"` directive. Follow app-store.ts persist pattern exactly.

    ```typescript
    interface WorkspaceState {
      // Panel open/collapsed flags
      leftDockOpen: boolean;
      rightDockOpen: boolean;
      bottomShelfOpen: boolean;

      // Panel sizes (percentage of parent container)
      leftDockSize: number;   // default 18, min 12, max 28
      rightDockSize: number;  // default 22, min 16, max 35

      // Actions
      toggleLeftDock: () => void;
      toggleRightDock: () => void;
      toggleBottomShelf: () => void;
      setLeftDockOpen: (open: boolean) => void;
      setRightDockOpen: (open: boolean) => void;
      setBottomShelfOpen: (open: boolean) => void;
      setLeftDockSize: (size: number) => void;
      setRightDockSize: (size: number) => void;
      resetLayout: () => void;
    }
    ```

    Implementation details:
    - Default state: `leftDockOpen: true, rightDockOpen: true, bottomShelfOpen: true, leftDockSize: 18, rightDockSize: 22`
    - `setLeftDockSize(size)`: clamp with `Math.min(28, Math.max(12, size))` before setting
    - `setRightDockSize(size)`: clamp with `Math.min(35, Math.max(16, size))` before setting
    - `resetLayout()`: set all 5 state fields back to defaults
    - persist config: `{ name: "bim-workspace-layout", partialize: (s) => ({ leftDockOpen: s.leftDockOpen, rightDockOpen: s.rightDockOpen, bottomShelfOpen: s.bottomShelfOpen, leftDockSize: s.leftDockSize, rightDockSize: s.rightDockSize }) }`

    The size constants (min/max/default) should be exported as named constants for use by WorkspaceShell in Phase 15:
    ```typescript
    export const LEFT_DOCK_MIN = 12;
    export const LEFT_DOCK_MAX = 28;
    export const LEFT_DOCK_DEFAULT = 18;
    export const RIGHT_DOCK_MIN = 16;
    export const RIGHT_DOCK_MAX = 35;
    export const RIGHT_DOCK_DEFAULT = 22;
    ```
