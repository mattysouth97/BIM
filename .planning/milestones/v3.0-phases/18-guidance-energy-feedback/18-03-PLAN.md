**Create src/hooks/use-energy-delta.ts (per D-06):**

A hook that provides snapshot/delta capabilities on top of useEnergyMetrics.

```typescript
interface EnergyDelta {
  /** Current metrics (live) */
  current: EnergyMetrics | null;
  /** Delta in kWh/m2 from snapshot (null if no snapshot taken) */
  demandDelta: number | null;
  /** Delta in CO2 kgCO2/m2 */
  co2Delta: number | null;
  /** Whether the delta represents improvement (negative = less demand = good) */
  isImprovement: boolean;
  /** Take a snapshot of current metrics (call on slider focus/pointerdown) */
  snapshot: () => void;
  /** Clear the snapshot and delta (call on blur or after timeout) */
  clearSnapshot: () => void;
  /** Whether a snapshot is active */
  hasSnapshot: boolean;
}
```

Implementation:
1. Accept `buildingPk: string` and optional `sigunguCd?: string`.
2. Call `useEnergyMetrics(buildingPk, sigunguCd)` to get live metrics.
3. Use `useRef<EnergyMetrics | null>(null)` to store the snapshot.
4. Use `useState<number | null>(null)` for demandDelta and co2Delta.
5. `snapshot()`: stores current metrics in the ref.
6. Compute deltas via `useMemo`: if snapshot ref is set and current metrics exist, `demandDelta = current.demand.demandPerSqm - snapshot.demand.demandPerSqm`. Same for CO2.
7. `isImprovement = (demandDelta ?? 0) < 0` (negative delta = demand went down = good).
8. `clearSnapshot()`: nulls the ref and resets deltas.
9. Add an auto-dismiss timer: use `useEffect` that starts a 4-second timeout after demandDelta changes to a non-null value. On timeout, call clearSnapshot(). Reset the timer if demandDelta changes again. Clear timeout on unmount.

Export `useEnergyDelta` and the `EnergyDelta` interface.

**Update src/components/workspace/properties-panel.tsx:**

1. Import `useEnergyDelta` from `@/hooks/use-energy-delta`.

2. Call `useEnergyDelta(buildingPk)` in the properties panel component (or in a sub-component that wraps energy-affecting sliders). The buildingPk comes from the same source as the existing panel props (likely "" placeholder per Phase 17 pattern).

3. For each energy-affecting slider (wall U-value, window U-value, WWR, insulation thickness, SHGC, airtightness — any slider that modifies material-store or recipe-store values affecting heat loss), add:
   - `onFocus` or `onPointerDown` handler that calls `energyDelta.snapshot()`
   - After the slider label/value, render a delta annotation when `energyDelta.demandDelta !== null`:
     ```tsx
     {energyDelta.demandDelta !== null && (
       <span className={cn(
         "text-[10px] font-medium tabular-nums ml-2 transition-opacity duration-300",
         energyDelta.isImprovement ? "text-green-600" : "text-amber-600"
       )}>
         {energyDelta.demandDelta > 0 ? "+" : ""}
         {energyDelta.demandDelta.toFixed(1)} kWh/m²
       </span>
     )}
     ```
   - The annotation auto-dismisses after 4 seconds (handled by the hook).

4. If the properties panel has multiple slider sections (e.g., wall properties, window properties, recipe overrides), the single useEnergyDelta instance covers all of them since any property change updates the same energy metrics.

5. Do NOT add delta annotations to non-energy sliders (e.g., visual-only material color, texture scale). Only energy-affecting properties get the annotation.

6. Color coding per research:
   - Green (`text-green-600`): demand decreased (improvement)
   - Amber (`text-amber-600`): demand increased (degradation)
   - Skip gray for neutral — the 4-second auto-dismiss handles small changes naturally.

7. Precision: 1 decimal place per research pitfall about misleading precision.
