## Key Accomplishments

1. **Real cadastral footprint extrusion** — buildings render with actual polygon shapes from VWorld (L-shaped, irregular, rectilinear) instead of rectangular boxes
2. **proj4 coordinate foundation** — site-specific Transverse Mercator projection with <1m accuracy at 2km, solving float32 precision issues with Korean EPSG:5179 coordinates
3. **earcut polygon triangulation** — concave and holed polygons triangulate correctly, replacing Three.js ShapeGeometry which fails on complex cadastral shapes
4. **Parallel data fetch pipeline** — building ledger + VWorld footprint fire simultaneously via useQueries, with graceful rectangular fallback
5. **VWorld API security** — hardcoded API key moved to environment variable with typed error on missing config
6. **Facade system on polygon buildings** — era-based PBR textures, mullions, and panels work on N-sided polygon buildings, not just 4-face rectangles
