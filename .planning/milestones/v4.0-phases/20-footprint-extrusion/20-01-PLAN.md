    - Resulting geometry has fewer triangles than a solid rectangle (hole creates gap)
    - Index count is non-zero

    Test 4 (winding order / face orientation):
    - Input: simple triangle [[[0,0],[1,0],[0,1],[0,0]]], height=1
    - Top cap face: vertices at y=heightMeters, normal points up (+Y)
    - Bottom cap face: vertices at y=0, normal points down (-Y)
    - Side faces: normals point outward from polygon centroid

    GREEN phase — implement extrudePolygon():

    Function signature:
    ```typescript
    export function extrudePolygon(
      rings: [number, number][][],  // [outerRing, ...holes] — each point is [x, z] in local meters
      heightMeters: number,
      baseY: number = 0,            // Y position of the base (for per-floor stacking)
    ): THREE.BufferGeometry
    ```

    Implementation:
    1. Use earcut.flatten() on 2D rings (dimensions=2): each point [x, z]
    2. Run earcut() to get triangle indices for the XZ plane cap
    3. Build position Float32Array with 3 groups of vertices:
       a. Bottom cap: all vertices at y = baseY (winding reversed for downward normal)
       b. Top cap: all vertices at y = baseY + heightMeters (earcut winding = upward normal)
       c. Side quads: for each consecutive edge pair [i, i+1] of outer ring, emit 2 triangles
          connecting bottom-left, bottom-right, top-right (+ top-right, top-left, bottom-left)
    4. For top cap: earcut indices map directly → positions at top-cap vertex range
    5. For bottom cap: reverse earcut index winding (swap [i] and [i+2] of each triangle) for correct face orientation
    6. Compute vertex normals via geo.computeVertexNormals()
    7. Return completed BufferGeometry

    Side quad winding (outward normal):
    - For edge from p[i] → p[i+1] (CCW outer ring):
      - v0 = [p[i].x, baseY, p[i].z]
      - v1 = [p[i+1].x, baseY, p[i+1].z]
      - v2 = [p[i+1].x, baseY+height, p[i+1].z]
      - v3 = [p[i].x, baseY+height, p[i].z]
      - Triangle 1: v0, v1, v2 (outward normal for CCW ring)
      - Triangle 2: v0, v2, v3

    Note: earcut expects CCW outer ring, CW holes (standard GeoJSON). If VWorld returns CW outer
    rings, detect and reverse: compute signed area; if positive = CCW (correct), if negative = CW (reverse).

    Signed area check:
    ```typescript
    function signedArea(ring: [number, number][]): number {
      let area = 0;
      for (let i = 0, j = ring.length - 1; i < ring.length; j = i++) {
        area += (ring[j][0] + ring[i][0]) * (ring[j][1] - ring[i][1]);
      }
      return area / 2;
    }
    // Positive = CCW in standard math (XZ plane), Negative = CW
    // earcut needs CCW outer ring
    ```
