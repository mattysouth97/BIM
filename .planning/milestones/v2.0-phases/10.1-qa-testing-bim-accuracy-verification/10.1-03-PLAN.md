<action>
Create `src/lib/procedural/__tests__/korean-typology.test.ts`:
- Define 3 benchmark Korean building typologies:
  1. **Standard apartment (아파트)**: 84m², 15 floors, RC, 2010s era
     - Expected: footprint ~10m × 8.4m, floor height ~2.9m, total height ~43.5m
     - Window ratio: ~30-40%, wall thickness: ~0.3m (RC with insulation)
  2. **Office building (업무시설)**: 500m², 8 floors, Steel, 2020s era
     - Expected: footprint ~25m × 20m, floor height ~3.5m
     - Window ratio: ~50-60%, curtain wall facade
  3. **Single family (단독주택)**: 120m², 2 floors, Masonry, 1990s era
     - Expected: footprint ~10m × 12m, floor height ~2.7m
     - Window ratio: ~20-30%, brick walls

- For each typology:
  - Create a mock BuildingGeometry with realistic Korean API data
  - Call toRecipe() → verify footprint, heights, era, wall thickness within ±20%
  - Call getRecipe() → verify facade config matches era expectations
  - Verify total wall area, window area, roof area are geometrically correct

Create `src/lib/energy/__tests__/bim-accuracy.test.ts`:
- Test against published Korean energy benchmarks:
  1. **Passive house target**: building with U-wall=0.15, U-roof=0.10, U-window=0.8, SHGC=0.4
     - Expected annual demand: <60 kWh/m²·yr (Grade 1+++ or 1++)
  2. **Code-minimum building (2020 Korean code)**: U-wall=0.24, U-roof=0.15, U-window=1.5
     - Expected annual demand: 120-180 kWh/m²·yr (Grade 1+ to 1)
  3. **Old uninsulated building (1970s)**: U-wall=2.0, U-roof=1.5, U-window=5.0
     - Expected annual demand: >300 kWh/m²·yr (Grade 5+)
- Verify CO2 emissions are proportional to demand
- Verify energy grade assignments match the expected ranges

Run `pnpm test` to verify all pass.
</action>
