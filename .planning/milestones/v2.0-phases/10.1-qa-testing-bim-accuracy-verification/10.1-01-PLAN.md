# Plan 01: Test Infrastructure + Unit Tests

<objective>
Set up Vitest + Playwright, then write comprehensive unit tests for energy calculations, procedural generators, and Zustand stores. Verify energy calcs against Korean building benchmarks.
</objective>

<tasks>

<task id="1">
<title>Test infrastructure setup</title>
<read_first>
- package.json
- tsconfig.json
</read_first>
<action>
Install test dependencies:
```bash
pnpm add -D vitest @testing-library/react @testing-library/jest-dom happy-dom @playwright/test
```

Create `vitest.config.ts`:
- Use happy-dom environment
- Path aliases matching tsconfig (@/ → src/)
- Include src/**/*.test.ts, src/**/*.test.tsx
- Exclude node_modules, .next, .planning
- Coverage with v8 provider

Create `playwright.config.ts`:
- Base URL: http://localhost:3000
- Projects: chromium only (for now)
- webServer: pnpm dev with reuseExistingServer

Update `package.json` scripts:
- "test": "vitest run"
- "test:watch": "vitest"
- "test:coverage": "vitest run --coverage"
- "test:e2e": "playwright test"
</action>
<acceptance_criteria>
- `vitest.config.ts` exists with happy-dom environment and path aliases
- `playwright.config.ts` exists with chromium project
- `package.json` has test, test:watch, test:coverage, test:e2e scripts
- `pnpm test` command runs (even if no tests yet)
</acceptance_criteria>
</task>

<title>Energy calculation unit tests</title>
<read_first>
- src/lib/energy/heat-loss.ts

<action>
Create `src/lib/energy/__tests__/heat-loss.test.ts`:
- Test calculateHeatLoss with a standard Korean apartment:
  - 84m² apartment, 15 floors, RC structure, 2010s era
  - Wall U-value: 0.26 W/(m²K), Roof: 0.15, Floor: 0.22, Window: 1.5
  - WWR: 40%, ΔT: 31.3°C (Seoul winter)
  - Expected total heat loss: verify within reasonable range (5000-15000W for 84m²)
- Test individual element breakdown (wall > window > roof for typical apartment)
- Test with zero area (edge case)
- Test with extreme U-values (insulated vs uninsulated)

Create `src/lib/energy/__tests__/annual-demand.test.ts`:
- Test with Seoul climate (HDD=2700, CDD=600)
- Benchmark: Korean 에너지효율등급 1등급 building should be <150 kWh/m²·yr
- Test HVAC efficiency impact: same building with 80% vs 95% heating efficiency
- Test floor area calculation: footprint × floor count

Create `src/lib/energy/__tests__/energy-grade.test.ts`:
- Test all grade boundaries: 59→1+++, 60→1++, 89→1++, 90→1+, etc.
- Test boundary values exactly at thresholds
- Test getGradeColor returns valid hex for each grade

Create `src/lib/energy/__tests__/co2-emissions.test.ts`:
- Test Korean grid factor (0.4594 tCO2/MWh)
- Test calculation: 100 kWh/m²·yr × 84m² × 0.4594/1000 = expected CO2
- Test zero demand case

Run `pnpm test` to verify all pass.
</action>
<acceptance_criteria>
