<task id="2">
<title>ECO2 export and import</title>
<read_first>
- src/store/material-store.ts
- src/store/recipe-store.ts
- src/lib/energy/heat-loss.ts
- src/lib/energy/annual-demand.ts

</read_first>
<action>
Create `src/lib/energy/eco2-export.ts`:
- Export `generateECO2Input(materials: MaterialProperties, recipe: BuildingRecipe, metrics: EnergyMetrics): string`
- Generate a JSON file (ECO2-compatible structure) with:
  - Building info: name, address, floor count, total area, era
  - Envelope: wall/roof/floor/window U-values, SHGC, WWR, airtightness
  - HVAC: system type, heating efficiency, cooling COP
  - Lighting: LPD
  - Calculated: heat loss, annual demand, grade, CO2
- Export `downloadECO2File(content: string, fileName: string): void`
  - Create Blob, URL.createObjectURL, trigger download

Create `src/lib/energy/eco2-import.ts`:
- Export `parseECO2Result(content: string): { grade: EnergyGrade, demand: number, co2: number } | null`
- Parse JSON result file from ECO2
- Extract energy grade and demand values
- Return structured result or null if parse fails

Update `src/components/viewer/viewer-overlay.tsx` or energy-cards.tsx:
- Add "Export ECO2" button (Download icon) near energy cards
- Add "Import ECO2" button (Upload icon) that opens file dialog
- On import: parse file, update energy grade display
</action>
<acceptance_criteria>

- Export/Import buttons visible near energy cards
- Download triggers file save dialog
- `pnpm build` passes
</acceptance_criteria>
</task>
