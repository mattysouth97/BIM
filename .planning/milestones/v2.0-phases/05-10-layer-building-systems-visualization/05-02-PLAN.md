- Export class `WasteLayer` implementing `LayerGenerator`
- Vertical waste chutes: InstancedMesh CylinderGeometry(0.15, 0.15, floorHeight, 8) per floor
  - 2 chute positions: rear face, 1/3 and 2/3 width
  - MeshStandardMaterial({ color: 0x65a30d, roughness: 0.9 })
- Collection points: BoxGeometry(1.0, 0.8, 0.6) at ground level under each chute
  - MeshStandardMaterial({ color: 0x78350f (brown) })

  - LineDashedMaterial({ color: 0x65a30d, dashSize: 0.3, gapSize: 0.15 })
- Group name: "layer-9-waste"

Create `src/lib/layers/layer-10-envelope.ts`:
- Export class `EnvelopeLayer` implementing `LayerGenerator`
- Surface panels: PlaneGeometry per facade face, subdivided into grid (3m x floor.height tiles)
  - Use InstancedMesh for panel tiles
  - ShaderMaterial with uTime for color-shifting effect:
    ```glsl
    uniform float uTime;
    varying vec2 vUv;
    void main() {
      float shift = sin(uTime * 0.5 + vUv.x * 6.28 + vUv.y * 3.14) * 0.5 + 0.5;
      vec3 color = mix(vec3(0.23, 0.51, 0.96), vec3(0.13, 0.77, 0.33), shift);
      gl_FragColor = vec4(color, 0.3);
    }
    ```
  - Transparent true, depthWrite false (overlay effect)
- Group name: "layer-10-envelope"
</action>
