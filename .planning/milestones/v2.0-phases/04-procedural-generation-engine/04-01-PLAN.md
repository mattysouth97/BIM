Create `src/lib/procedural/types.ts` with these exported types:

1. **FacadeConfig** — parameters controlling facade grid subdivision and instancing:
   - `windowWidth: number` (meters, from wall-geometry WIN table by era)
   - `windowHeight: number` (meters, from WIN table)
   - `sillHeight: number` (meters, distance from slab top to window bottom)
   - `windowSpacing: number` (meters, horizontal center-to-center)
   - `windowRatio: number` (0-1, from WINDOW_RATIOS)
   - `mullionDepth: number` (meters, how far mullions extrude outward from wall plane; era-based: pre-1970=0.03, 1970-1989=0.04, 1990-1999=0.05, 2000-2009=0.06, 2010-2019=0.08, 2020+=0.10)
   - `mullionWidth: number` (meters, cross-section width of mullion frame; 0.05 for all eras)
   - `glassInset: number` (meters, how far glass is pushed inward from wall face; 0.03 for all eras — Gemini facade approach)
   - `solidPanelChance: number` (0-1, probability a window cell becomes solid panel instead of glass; 0.15 per decision)
   - `parapetHeight: number` (meters, top-of-building parapet; flat=0.9, gable=0.3, other=0.6)
   - `cornerInset: number` (meters, how much frame elements pull back from building corners to avoid overlap; 0.05)

2. **SlabConfig**:
   - `thickness: number` (meters)
   - `overhang: number` (meters, slab extends beyond wall face; 0.0 for all — flush)

3. **ColumnConfig**:
   - `spacing: number` (meters)
   - `size: number` (meters, cross-section width)
   - `inset: number` (meters, distance from wall inner face; wallThickness + columnSize/2 + 0.05)

4. **RoofConfig**:
   - `type: "flat" | "gable" | "other"`
   - `flatThickness: number` (meters, 0.3)
   - `gableHeight: number` (meters, 3.0)
   - `hipInset: number` (meters, top-face inset for "other" type; 0.4 ratio)

5. **MaterialRefs** — references to material configs (NOT Three.js materials — those are created by the generator):
   - `wall: PBRMaterialConfig`
   - `glass: PBRMaterialConfig`
   - `mullion: PBRMaterialConfig` (color="#808890", roughness=0.4, metalness=0.6 — anodized aluminum)
   - `slab: PBRMaterialConfig`
   - `column: PBRMaterialConfig`
   - `roof: PBRMaterialConfig`
   - `groundFloor: PBRMaterialConfig`

6. **BuildingRecipe** — the top-level config:
   - `footprintWidth: number`
   - `footprintDepth: number`
   - `footprintPolygon?: [number, number][]`
   - `floors: FloorSpec[]` where FloorSpec = `{ floorNo: number; label: string; type: "above"|"below"; y: number; height: number; isGroundFloor: boolean }`
   - `totalHeight: number`
   - `wallThickness: number`
   - `era: BuildingEra`
   - `strctCd: string`
   - `mainPurpsCd: string`
   - `facade: FacadeConfig`
   - `slab: SlabConfig`
   - `column: ColumnConfig`
   - `roof: RoofConfig`
   - `materials: MaterialRefs`
   - `siteWidth: number`
   - `siteDepth: number`
   - `buildingName: string`
   - `address: string`

7. **RecipeOverrides** — Partial<Pick<BuildingRecipe, 'facade' | 'slab' | 'column' | 'roof'>> for user overrides from material-store.

Import BuildingEra from "@/lib/material-types" and PBRMaterialConfig from "@/lib/pbr-materials".

**A) Create `src/lib/procedural/recipe.ts`:**

Export `getRecipe(strctCd: string, era: BuildingEra, mainPurpsCd: string): { facade: FacadeConfig; slab: SlabConfig; column: ColumnConfig; roof: RoofConfig; materials: MaterialRefs }`:

For **facade**, derive from existing data:
- `windowWidth`, `windowHeight`, `sillHeight`, `windowSpacing`: use the same values as wall-geometry.ts WIN table (replicate or import — since WIN is not exported, replicate the table inline as `FACADE_WINDOW_DIMS`)
- `windowRatio`: from `WINDOW_RATIOS[era][getUseCategory(mainPurpsCd)]` — replicate the getUseCategory logic from building-geometry.ts
- `mullionDepth`: lookup table by era: `{ "pre-1970": 0.03, "1970-1989": 0.04, "1990-1999": 0.05, "2000-2009": 0.06, "2010-2019": 0.08, "2020+": 0.10 }`
- `mullionWidth`: 0.05 all eras
- `glassInset`: 0.03 all eras
- `solidPanelChance`: 0.15
- `parapetHeight`: 0.9 (adjusted by roof type in toRecipe)
- `cornerInset`: 0.05

For **slab**: `thickness` from building-geometry logic (by strctCd — steel=0.15, masonry=0.25, else=0.20), `overhang`: 0.0.

For **column**: `spacing` from building-geometry logic (steel=9, SRC=8, timber=4.5, else=6), `size` by strctCd and a `largeBuilding: boolean` parameter (default false; steel=0.3, large=0.6, else=0.4), `inset`: computed as wallThickness + columnSize/2 + 0.05 (but wallThickness not known here, so set `inset: 0` — will be recomputed in toRecipe).

For **roof**: `type: "flat"` default (overridden in toRecipe), `flatThickness: 0.3`, `gableHeight: 3.0`, `hipInset: 0.4`.

For **materials**: call `getPBRMaterial(strctCd, mainPurpsCd, era)` for wall. Use `WINDOW_MATERIAL` for glass. Mullion: `{ color: "#808890", roughness: 0.4, metalness: 0.6 }`. Slab/column: call `getPBRMaterial(strctCd, undefined, era)`. Roof: `ROOF_MATERIALS["flat"]` default. Ground floor: call `getGroundFloorMaterial(mainPurpsCd)`.

Export `applyOverrides(recipe: BuildingRecipe, overrides: RecipeOverrides): BuildingRecipe`:
- Deep-merge overrides into recipe's facade/slab/column/roof sub-objects.
- Return new object (immutable).

**B) Add `toRecipe()` to `src/lib/building-geometry.ts`:**

At the bottom of the file, add:
```typescript
import type { BuildingRecipe } from "./procedural/types";
import { getRecipe } from "./procedural/recipe";
```

Export function `toRecipe(geo: BuildingGeometry): BuildingRecipe` that:
1. Calls `getRecipe(geo.strctCd, geo.era, geo.mainPurpsCd)` for defaults
2. Maps `geo.floors` to `FloorSpec[]` (pick floorNo, label, type, y, height, isGroundFloor — drop width/depth/area/use/color which are building-level)
3. Sets `footprintWidth`, `footprintDepth`, `footprintPolygon`, `totalHeight`, `wallThickness` from geo
4. Overrides `column.inset = geo.wallThickness + recipe.column.size / 2 + 0.05`
5. Overrides `column.size` using geo.columnSize, `column.spacing` using geo.columnSpacing
6. Overrides `slab.thickness` using geo.slabThickness
7. Sets `roof.type = geo.roofType`; adjusts `facade.parapetHeight` by roof type (flat=0.9, gable=0.3, other=0.6)
8. Sets `materials.roof = ROOF_MATERIALS[geo.roofType] || ROOF_MATERIALS.flat`
9. Copies `siteWidth`, `siteDepth`, `buildingName`, `address`, `era`, `strctCd`, `mainPurpsCd`
10. Returns complete BuildingRecipe

Import `ROOF_MATERIALS` from `./pbr-materials` (already indirectly used in roof-generator.tsx).

Do NOT modify the existing `generateBuildingGeometry()` function — toRecipe is additive.
