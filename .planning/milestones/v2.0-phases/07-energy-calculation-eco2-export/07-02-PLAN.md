# Plan 02: Component Library + Component Store

<objective>
Create a component library system with a drag-and-drop palette panel. Includes procedural generators for doors, windows, MEP fixtures, and stairs — each with Korean standard presets. Components snap to walls and integrate with the 14-layer system.
</objective>

<tasks>

<task id="1">
<title>Component types and store</title>
<read_first>
- src/store/authoring-store.ts
- src/lib/procedural/types.ts
- src/lib/layers/types.ts
</read_first>
<action>
Create `src/lib/components/component-types.ts`:
- Export `ComponentCategory`: "door" | "window" | "mep" | "stair"
- Export `ComponentPreset` interface:
  - id: string, name: string, nameKo: string, category: ComponentCategory
  - width: number, height: number, depth: number
  - layerId?: LayerId (for MEP fixtures — which layer they belong to)
  - metadata: Record&lt;string, unknown&gt; (type-specific properties)
- Export `PlacedComponent` interface:
  - instanceId: string (uuid), presetId: string
  - position: [number, number, number], rotation: [number, number, number]
  - parentWallId?: string (for doors/windows snapped to walls)
  - buildingPk: string
- Export `DOOR_PRESETS`: array of ComponentPreset with Korean standard sizes:
  - 900x2100mm single, 1000x2100mm single, 1200x2100mm double
- Export `WINDOW_PRESETS`: 1200x1500mm, 1800x1500mm, 2400x1500mm
- Export `MEP_PRESETS`: sprinkler head (layer 13), BAS sensor (layer 10), light fixture (layer 7), HVAC vent (layer 5), fire alarm (layer 13)
- Export `STAIR_PRESETS`: standard (1200mm wide), wide (1500mm), spiral

Create `src/store/component-store.ts`:
- Zustand store (non-persisted)
- State: placed: Record&lt;string, PlacedComponent[]&gt; (keyed by buildingPk)
- State: dragging: ComponentPreset | null (currently being dragged from palette)
- Actions: placeComponent(pk, component), removeComponent(pk, instanceId), updatePosition(pk, instanceId, pos), setDragging(preset | null)
- Export as `useComponentStore`
</action>
<acceptance_criteria>
- `src/lib/components/component-types.ts` contains `ComponentPreset`, `PlacedComponent`, `DOOR_PRESETS`, `WINDOW_PRESETS`, `MEP_PRESETS`, `STAIR_PRESETS`
- Door presets have Korean standard dimensions (900x2100, 1000x2100, 1200x2100 in meters)
- MEP presets reference correct LayerId values
- `src/store/component-store.ts` contains `useComponentStore`
- `pnpm build` passes
</acceptance_criteria>
</task>

<task id="2">
<title>Component geometry generators</title>
<read_first>
- src/lib/components/component-types.ts
- src/lib/procedural/facade-generator.ts
- src/lib/layers/layer-7-lighting.ts
</read_first>
<action>
Create `src/lib/components/door-generator.ts`:
- Export `generateDoor(preset: ComponentPreset): THREE.Group`
- Door frame: BoxGeometry with hole (use CSG or outline edges)
  - Frame material: MeshStandardMaterial({ color: 0x8B4513, roughness: 0.7 }) — wood brown
- Door panel: BoxGeometry slightly inset, with handle (small CylinderGeometry)
- Korean standard proportions
- Group name: "component-door"

Create `src/lib/components/window-generator.ts`:
- Export `generateWindow(preset: ComponentPreset): THREE.Group`
- Window frame: BoxGeometry outline
  - Frame material: MeshStandardMaterial({ color: 0xc0c0c0, metalness: 0.5 }) — aluminum
- Glass pane: PlaneGeometry with MeshPhysicalMaterial({ transmission: 0.9, roughness: 0.05 })
- Mullion dividers based on preset width
- Group name: "component-window"

Create `src/lib/components/mep-fixture-generator.ts`:
- Export `generateMEPFixture(preset: ComponentPreset): THREE.Group`
- Switch on preset.id for different fixture types:
  - "sprinkler": CylinderGeometry head + small SphereGeometry bulb (red)
  - "bas-sensor": IcosahedronGeometry (green, matching layer-10-bas)
  - "light-fixture": flat BoxGeometry with emissive white (matching layer-7-lighting)
  - "hvac-vent": BoxGeometry with grille lines (cyan)
  - "fire-alarm": small BoxGeometry with red emissive
- Group name: "component-mep-{id}"

Create `src/lib/components/stair-generator.ts`:
- Export `generateStair(preset: ComponentPreset): THREE.Group`
- Standard: BoxGeometry treads stacked vertically (floor height / 0.17m riser height = step count)
- Stringer sides as thin BoxGeometry
- Handrail as CylinderGeometry along stringer top edge
- Spiral: steps arranged in a spiral using rotation math
- Group name: "component-stair"
</action>
<acceptance_criteria>
- All 4 generator files exist in src/lib/components/
- Each exports a `generate*` function returning THREE.Group
- Door has frame + panel + handle
- Window has frame + glass + mullions
- MEP fixtures match their layer visual style
- Stair has treads + stringer + handrail
- `pnpm build` passes
</acceptance_criteria>
</task>
