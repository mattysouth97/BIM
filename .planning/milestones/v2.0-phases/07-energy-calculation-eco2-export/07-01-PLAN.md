# Plan 01: Element Selection + Transform Gizmo + Properties Panel

<objective>
Enable click-to-select on building elements, display Three.js TransformControls gizmo for translate/rotate/scale, show a properties panel with editable dimensions, and implement undo/redo with a command pattern stack.
</objective>

<tasks>

<task id="1">
<title>Authoring store with undo/redo</title>
<read_first>
- src/store/recipe-store.ts
- src/store/material-store.ts
- src/lib/procedural/types.ts
</read_first>
<action>
Create `src/store/authoring-store.ts`:
- Interface `ElementEdit`: { elementId: string, property: string, oldValue: unknown, newValue: unknown, timestamp: number }
- Interface `AuthoringState`:
  - selectedElementId: string | null
  - selectedElementType: "wall" | "slab" | "column" | "roof" | "component" | null
  - transformMode: "translate" | "rotate" | "scale"
  - editHistory: ElementEdit[] (undo stack)
  - redoHistory: ElementEdit[] (redo stack)
  - isAuthoring: boolean (toggle between view/edit mode)
- Actions:
  - selectElement(id: string | null, type: string | null)
  - setTransformMode(mode: "translate" | "rotate" | "scale")
  - pushEdit(edit: ElementEdit) — push to editHistory, clear redoHistory
  - undo() — pop from editHistory, push to redoHistory, apply oldValue
  - redo() — pop from redoHistory, push to editHistory, apply newValue
  - toggleAuthoring() — toggle isAuthoring
  - clearSelection()
- Export as `useAuthoringStore`
</action>
<acceptance_criteria>
- `src/store/authoring-store.ts` contains `export const useAuthoringStore`
- Store has `selectElement`, `setTransformMode`, `pushEdit`, `undo`, `redo`, `toggleAuthoring`
- Undo/redo use command pattern (ElementEdit with oldValue/newValue)
- `pnpm build` passes
</acceptance_criteria>
</task>
