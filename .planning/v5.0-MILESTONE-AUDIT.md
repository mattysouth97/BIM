## Critical Gap Discovered & Fixed Mid-Milestone

**MEP generators never invoked until Phase 28 gap-wiring.** The MEP layer generators (CoolingLayer, HeatingLayer, VentilationLayer, DHWLayer, LightingLayer) were defined in src/lib/layers/ but NEVER called in production code. This made:
- Phase 22 sub-toggles toggle empty groups
- Phase 26 click selection have nothing to hit
- Phase 28 procedural params have nothing to update

**Fix:** New useEffect in BuildingLayers that subscribes to equipment-store params, calls each generator, routes via assignToSubGroup. Documented in `.planning/phases/28-procedural-mep-equipment-models/28-GAP-WIRING-SUMMARY.md`.

**Lesson learned:** Generator code without production wiring is dead code. Future milestones should verify integration as part of the first phase that introduces the generators.

## Critical Bug Fixed

**EquipmentTab snapshot caching error.** Original implementation used `useEquipmentStore((s) => s.getParams(pk))` where `getParams` returned `JSON.parse(JSON.stringify(DEFAULT))` for missing pks → new object reference every render → React infinite loop warning. Fixed by subscribing to `s.params[pk]` directly with stable default fallback.
